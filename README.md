# CentralCrypto Academy Images

Imagens das aulas geradas automaticamente via worker.

## Estrutura

```
{slug-do-topico}/
  img1.png
  img2.png
  ...
```

O slug e derivado do titulo do topico (ASCII lowercase, espacos -> underscore, max 40 chars).

## URL padrao

```
https://raw.githubusercontent.com/CentralCrypto/academyimg/main/{slug}/img{n}.png
```
